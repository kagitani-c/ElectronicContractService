# Web電子契約サービス（Electronic Contract Service）

国際標準規格 **PAdES（PDF-Advanced Electronic Signatures）** に準拠し、契約締結における「法的証拠力」と「非改ざん性」を実証・体験できるSaaS型Web電子契約システムです。

Java / Jakarta EE による堅牢なMVCアーキテクチャをベースに、公開鍵暗号基盤（PKI）を用いたデジタル署名の生成・埋め込みから、SHA-256ハッシュ照合による1ビット単位の改ざん検知機能までを一気通貫で実装しています。

---

## 1. プロジェクトの目的・開発背景

* **電子契約における「完全性」の可視化**:  
  多くの電子契約サービスではブラックボックス化されがちな「電子署名・暗号検証の仕組み」を自らコード化し、技術的根拠に基づいたセキュアな契約締結プロセスを証明すること。
* **業務導線と権限管理の最適化**:  
  契約送信者（本登録ユーザー）と受信者（招待ゲスト）の権限・画面遷移を厳格に分離し、安全かつ直感的に署名まで到達できるUXの実現。
* **ポータビリティ（環境再現性）の担保**:  
  外部データベースサーバーの導入を不要とし、ローカルクローン後すぐに実行・検証できる再現性の高い環境構築。

---

## 2. 主な機能一覧

### ① 電子署名・暗号セキュリティ（コア機能）
* **PAdES規格準拠のPDF電子署名（Bouncy Castle / Apache PDFBox）**:
  * PDF内部の署名辞書（`/ByteRange`, `/Contents`）を解析・生成し、SHA256withRSAによる分離署名（Detached CMS）を直接埋め込み。
* **電子証明書管理（発行・アップロード両対応）**:
  * **テスト用即時発行**: RSA 2048bit鍵ペアおよび自己署名X.509証明書をシステム内でワンクリック生成。
  * **外部証明書連携**: 外部で取得した PKCS#12（`.p12` / `.pfx`）ファイルや `.txt` 証明書ファイルのインポート・紐付けに対応。
* **暗号検証・改ざん検知シミュレーター（Signature Lab）**:
  * 署名済みPDFの原本ハッシュ値と現在のハッシュ値を比較照合。
  * 意図的にPDFバイナリ末尾を改ざん（バイト追記）または復元し、1ビットの差異でも署名が無効化される暗号数学的検証をシミュレート。

### ② 契約業務・フォルダー管理
* **契約フォルダー管理**:
  * 契約書類のグルーピング管理、宛先企業・担当者情報の登録および変更履歴（`FolderHistory`）の自動保存。
* **契約書ドキュメント管理・版数管理**:
  * PDFアップロード、ブラウザ上でのインラインプレビュー（`inline` 配信）、ダウンロード。
  * 契約書の差し替え（版数カウントアップ）および論理削除（アーカイブ）機能。
* **ステータス・ライフサイクル制御**:
  * 「下書き（`DRAFT`）」→「署名待ち（`WAITING_SIGN`）」→「締結完了（`COMPLETED`）」の自動遷移。

### ③ アカウント・権限分離（ゲストアクセス）
* **ダッシュボード統合**:
  * ログイン直後に案件状況のサマリー指標と電子証明書ステータス、クイックアクションを集約表示。
* **ワンタイム招待トークンとゲスト自動アカウント生成**:
  * 招待URL経由でアクセスした取引先担当者に対し、パスワード入力による即時アカウント作成（`INVITED` 権限）とフォルダー自動紐付け。
  * ゲストユーザーに対する不正な新規フォルダー作成・証明書発行のガード処理。

## 3. 技術スタック

| 分野 | 技術 / ツール | 用途・詳細 |
| :--- | :--- | :--- |
| **言語** | Java (JDK 17) | バックエンドビジネスロジック、暗号処理 |
| **フレームワーク / 仕様** | Jakarta EE (Servlet 6.0 / JSP) | MVCアーキテクチャの制御・画面描画 |
| **暗号 / PDF処理** | Bouncy Castle (bcprov, bcpkix)<br>Apache PDFBox 2.x | PAdES電子署名生成、X.509証明書パース、PDFバイナリ解析 |
| **データベース** | H2 Database (埋め込みモード) | アカウント、フォルダー、契約書、署名メタデータの永続化 |
| **データアクセス** | JDBC (PreparedStatement) | SQLインジェクション防止、リソース管理 |
| **フロントエンド** | HTML5 / CSS3 / JSTL | レスポンシブUI、サイドバーレイアウト |
| **開発・管理環境** | Eclipse / Maven / Git / GitHub | ビルド、依存関係解決、ソース管理 |
